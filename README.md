# PHPStan Brick Extensions

PHPStan extensions that narrow throw types for [brick/math](https://github.com/brick/math) and [brick/money](https://github.com/brick/money).

This is a monorepo. Packages are split into read-only repositories:
- [simpod/phpstan-brick-math](https://github.com/simPod/phpstan-brick-math)
- [simpod/phpstan-brick-money](https://github.com/simPod/phpstan-brick-money)
